# Inversion Speaking Practice — Dmitry Timoshenko **Level:** B2 | **Focus:** Register expansion beyond *however / as a result*; C1-level contrast nuance; speaking fluency with inversion structures **Context:** robotics, network engineering, IT, career abroad --- ## Exercise 1 — Emphatic Reformulation Drill (Contrast → Inversion Upgrade) **How to run it:** Read each sentence aloud. Dmitry reformulates it using an inversion structure instead of the contrast connector, keeping the meaning intact. Push for immediate, spoken responses — no writing. If he freezes, offer the starter word only (e.g., "Rarely..."). **Target structures to rotate through:** *Rarely... / Never... / Not once... / Only when... / Little did... / So... that... / Under no circumstances...* | # | Prompt (with however/despite/as a result) | Target inversion (model answer) | |---|---|---| | 1 | However, the network held up despite the heavy load. | Rarely has a network held up so well despite such a heavy load. | | 2 | Despite the tight deadline, the team delivered the prototype on time. | So tight was the deadline that few believed the prototype would arrive on time. | | 3 | However, we hadn't tested the sensor properly, and as a result, it failed in the field. | Not until we lost the sensor in the field did we realize how poorly it had been tested. | | 4 | Despite his lack of experience, he was promoted to lead engineer. | Rarely does someone with so little experience get promoted to lead engineer. | | 5 | However, the client was satisfied, and as a result, they extended the contract. | Only after seeing the results did the client agree to extend the contract. | | 6 | Despite the budget cuts, the robotics division kept innovating. | Under no circumstances did the robotics division let budget cuts slow its innovation. | | 7 | However, I had never worked with this framework before, so it was difficult at first. | Never had I worked with this framework before, so the first weeks were difficult. | | 8 | Despite multiple failures, the team refused to abandon the project. | Not once did the team consider abandoning the project, despite multiple failures. | | 9 | However, the code passed all tests, and as a result, we were confident to deploy. | Only once the code had passed all tests did we feel confident enough to deploy. | | 10 | Despite moving abroad, he kept in close contact with his old team. | Rarely does someone stay as close to a former team as he did after moving abroad. | **Follow-up:** Ask Dmitry to produce 2 more of his own — one about a real project, one about his plans to work abroad. --- ## Exercise 2 — Finish the Inversion (IT / Robotics Prompts) **How to run it:** Give the starter clause only. Dmitry completes it spontaneously and speaks the full sentence. Encourage technical/robotics vocabulary. Do 2–3 rounds per starter if time allows, pushing for different content each time. 1. Not only does this system... 2. So complex was the architecture that... 3. Rarely have I worked with a team that... 4. Never before had the sensors... 5. Only by running extensive tests can we... 6. Little did the client know that... 7. No sooner had we deployed the update than... 8. Under no circumstances should a developer... 9. Not until the final review did we... 10. So unreliable was the connection that... 11. Only when the firmware was rewritten did... 12. Seldom does a network engineer encounter... **Extension task:** Choose any 3 completed sentences and link them into a short 4–5 sentence account of a real or imagined project — practicing flow, not just isolated lines. --- ## Exercise 3 — Debate Stance Cards (Inversion as Rebuttal Opener) **How to run it:** Present each topic/claim. Dmitry must open his response (agreeing or disagreeing) with an inversion structure, then defend the stance for 30–60 seconds. These double as Debate&Beyond Team 0 prep. | Topic | Claim | Suggested inversion opener | |---|---|---| | IoT & Security | "Companies should be allowed to deploy IoT devices without strict security regulation." | Under no circumstances should companies deploy IoT devices without proper regulation. | | Robots & Robotics | "Robots will eventually replace most engineering jobs." | Only when robots can reason independently will they truly replace engineers. | | Entrepreneurship | "Anyone can become a successful entrepreneur with enough hard work." | Rarely does hard work alone guarantee entrepreneurial success. | | Money & Finances | "Job security matters more than salary when choosing a career abroad." | Not only does salary matter, but so does long-term job security. | | Time Management | "Multitasking makes engineers more productive." | Seldom does multitasking actually improve an engineer's productivity. | | Staying Healthy | "Remote work is better for a person's health than office work." | Only with strict self-discipline is remote work genuinely healthier than office work. | **Follow-up:** After each stance, ask Dmitry to counter his own argument using a second inversion structure — practicing balanced, C1-level argumentation. --- ### Teacher notes - Sequence used: Exercise 4 (Reformulation) → Exercise 6 (Finish the Inversion) → Exercise 3 (Debate Stance Cards) — increasing in spontaneity and cognitive load. - Correct only after each full turn, not mid-sentence, to protect fluency. - Flag any recurring return to *however/as a result* for follow-up in the next writing lesson.
