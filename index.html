🔤 Present Simple: -s or -es?

He / She / It — third person singular

📝 Rules for He / She / It

Most verbs → + s

Just add -s

play → plays
eat → eats
read → reads

-s, -ss, -sh, -ch, -x, -o → + es

Add -es

go → goes
watch → watches
wash → washes
mix → mixes

Consonant + y → ies

Change y → ies

study → studies
fly → flies
carry → carries

Vowel + y → + s

Just add -s

play → plays
enjoy → enjoys
buy → buys
