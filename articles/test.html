Section 1
Apply the Algorithm
For each sentence, choose the correct article by following the 4-step algorithm. Think before you click!
1
Is the noun definite (known/unique) or indefinite? → Definite = the
2
If indefinite — is it singular or plural? → Plural = ∅ (zero)
3
If singular — is it countable or uncountable? → Uncountable = ∅ (zero)
4
If singular + countable — does the next word start with a vowel sound? → Yes = an, No = a
