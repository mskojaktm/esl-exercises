Exercise 1 · Warm-up: ten very tricky sentences

Translate each Russian sentence into English. Every sentence hides two to four gerund/infinitive traps — meaning-change verbs, used to, perception verbs, prepositions, complex forms. Write your own translation first; open the vocabulary help only if you are stuck.
Rule map (open only if you get stuck)
  1. enjoy / avoid / suggest / deny… + -ing
  2. want / decide / manage / afford… + to V
  3. begin / start / like / prefer… — either form
  4. remember, forget, stop, try, regret, mean, go on, need — meaning changes
  5. used to V · be / get used to -ing
  6. advise / tell / allow / persuade + object + to V
  7. make / let (+ help) + object + bare V
  8. see / hear / notice + object + V (whole) or -ing (in progress)
  9. preposition + -ing (look forward to, instead of, without)
  10. gerund as subject · it's no use / no point in / can't help -ing
  11. purpose: to V / in order to / so as (not) to
  12. adjective + to V · it's kind of you / difficult for me
  13. too + adj + to V · adj + enough + to V
  14. perfect / passive / continuous forms: having done, being done, to have done, to be doing
The structure check is automatic and approximate: it looks for the target pattern in your text. A correct alternative may be marked ✗ — compare with the model translation, and your teacher has the final word.
